### 🔗 [Nexus — Investor & Entrepreneur Collaboration Platform](https://github.com/Muhammad-Shoaib-1/Nexus)
A full-stack MERN platform connecting entrepreneurs raising funding with investors — built during a full-stack development internship.
- Real-time chat, collaboration requests, and meeting scheduling with conflict detection
- Peer-to-peer video calling via WebRTC + Socket.IO signaling
- Document upload/e-signing, investor deal pipeline, and a simulated payments sandbox
- JWT auth, 2FA, input validation, and rate limiting

**Stack:** React · TypeScript · Node.js · Express · MongoDB · Socket.IO
